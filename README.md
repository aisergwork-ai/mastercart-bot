# Бот-примерочная деревянных карт

Telegram-бот: клиент выбирает карту в каталоге, присылает фото своей стены и
получает фотореалистичную примерку (как карта будет смотреться у него, с
подсветкой), затем может оставить заявку.

## Как работает

- **Каталог** — категории (Карты мира / Карты России) → карточки товаров
  (фото + описание). Товары в `catalog.py`, картинки в `assets/`.
- **Примерка** — «🪄 Примерить на свою стену» → клиент шлёт фото → бот через
  Nano Banana (Gemini Image, AITUNNEL) вставляет карту на стену с тенями,
  светом и подсветкой → возвращает картинку. Лимит бесплатных примерок в сутки
  настраивается (`MOCKUP_DAILY_LIMIT`).
- **Заявка** — «🛒 Заказать» → имя + телефон → сохраняется в БД и падает в чат
  менеджеров (`/setleadchat` или `LEAD_CHAT_ID`). `/leads` — последние заявки.

Первый, кто напишет `/start` (если не задан `ADMIN_IDS`), становится админом.

## Запуск локально

```bash
pip install -r requirements.txt
cp .env.example .env   # заполни BOT_TOKEN, AITUNNEL_KEY
export $(grep -v '^#' .env | xargs)
python bot.py
```

## Деплой на Railway

1. New Project → Deploy from GitHub repo → этот репозиторий.
2. Variables: `BOT_TOKEN`, `AITUNNEL_KEY`, при желании `ADMIN_IDS`, `LEAD_CHAT_ID`,
   `MOCKUP_DAILY_LIMIT`.
3. **Volume** в `/data` + `DB_PATH=/data/bot.db` — иначе заявки и лимиты теряются
   при передеплое.
4. Procfile (`worker: python bot.py`) Railway определит сам.

Telegram недоступен из российских облаков — хостить вне РФ (Railway). Запросы к
AITUNNEL идут на `api.aitunnel.ru` (работает и из РФ).

## Расширение каталога

Добавь запись в `PRODUCTS` (`catalog.py`) и файл изображения в `assets/`.
Картинка товара используется и в карточке, и для примерки — чем качественнее
фото изделия, тем реалистичнее результат.
